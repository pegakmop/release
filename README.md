## https://pegakmop.github.io/release/

# Установить репозиторий на ваше устройство.
```
curl -Ls "https://pegakmop.github.io/release/keenetic/opkg.sh" | sh
```

# Установить neofit на xray или sing-box-go версии:

neofitsb install
```
opkg install neofitsb
```

neofitxray install
```
opkg install neofitxray
```

neofitsb remove
```
opkg remove neofitsb
```

neofitxray remove
```
opkg remove neofitxray
```
